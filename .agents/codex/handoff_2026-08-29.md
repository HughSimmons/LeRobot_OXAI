## Calibration Geometry Clarification

The calibration distinguishes three physical edge classes:

1. Shared bottom table edge / robot back edge
   - This is one edge, not two.
   - It is flush with the back of the robot base.
   - The user has measured this edge span as `0.50 m`.
   - The user should click the measured endpoints of this 50 cm span; optional intermediate points only improve line fitting.

2. Right-hand table edge
   - Perpendicular to the shared bottom/robot edge.
   - Used with edge 1 to establish the table-plane frame.

3. Elevation-change edge
   - Where the raised board/extended board surface ends and the surface drops to table height.
   - Used for the elevation-aware estimate.

The script compares three methods:

- Board-plane homography only.
- Table-plane homography using the bottom and right table edges.
- Elevation-aware hybrid:
  - board/elevated homography from board centre to the elevation-change edge;
  - table homography from the elevation-change edge down to the bottom/robot edge.
